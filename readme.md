A powerful, fully working automator that runs directly in your browser to help with Microsoft Rewards tasks. It is completely free and open source.

The project is still actively being developed every day, but it is already fully functional and usable. Despite that, it manages to stay extremely lightweight, sitting at around ~1MB after being compiled (including the icon).

This is the official GitHub repository of the extension. You probably won't find this on any web store, as it was not submitted due to Microsoft Rewards rules and Terms of Service.

## What is this?

Rewards Automator is a small browser extension made to automate repetitive tasks directly from your browser. The goal was to keep it simple, fast, and lightweight without turning it into some huge application that takes forever to load.

Everything is done locally inside the browser. There is no weird installer, no unnecessary background program, and no massive package filled with things that are never used.

## Development

This project is still far from perfect. It is constantly being worked on, improved, and occasionally broken while adding new stuff.
The source code is fully available, so feel free to look through it, modify it, or point out anything that can be improved.
Please expect some spaghetti code held together with duct tape, random fixes, and questionable decisions. I'm still learning both English and programming, so the code quality might not always be the best.

## Features

- Lightweight and fast
- Runs entirely inside your browser
- Small compiled size (~1MB)
- Fully open source
- No paid features
- Constantly updated
- Easy to modify
