A powerful, fully working automator that runs directly in your browser to help with Microsoft Rewards tasks. It is completely free and open source.
This is the official GitHub repository of the extension. You probably won't find this on any web store as it was not submitted due to Microsoft Rewards rules/ToS

## Quick disclaimer

It's obvious that you are using a macro, which is banned (skill issues if you get banned). Please do not use this unless you are greedy and lazy like me. Your account, your responsibility
It's always good to read the rules/ToS of all services you use so the application won't act as an obstacle that might affect your account

## What is this?

Rewards Automator is a small browser extension made to automate repetitive tasks directly from your browser. The original goal was to make it simple, fast and while not turning into a big mess
Everything is done locally inside the browser. There is no weird installer, no unnecessary background program, and no massive package filled with things that are never used.

## Development

This project is still far from perfect. It is constantly being worked on, improved, and occasionally broken while adding new stuff.
Please expect some spaghetti code held together with duct tape, random fixes, and questionable decisions. I'm still learning both English and programming.

## Features

- Lightweight
- Run entirely locally
- Small size (~1MB)
- Easy to modify
